# Сервис переозвучки лекций (EN → RU)

Видео → расшифровка (Whisper) → перевод (локальная LLM в LM Studio) → **проверка перевода в браузере** → озвучка
голосом диктора (F5-TTS Russian + RUAccent) → видео с русской дорожкой. Видео берётся загрузкой файла или из курса Teachbase.

Все модели открытые и работают локально. Лицензия весов озвучки F5-TTS Russian — **CC-BY-NC-4.0, только некоммерческое использование**.

## Требования
- Python 3.10+, `ffmpeg` в PATH, NVIDIA GPU (проверено на RTX 2070 8 ГБ; для больших `ASR_MODEL` нужна память с запасом).
- LM Studio с запущенным локальным сервером (по умолчанию `http://localhost:1234/v1`). Может стоять на другом ПК: `DUB_LLM_URL`.
- Интернет при первом запуске: скачиваются Whisper large-v3 и medium, вокодер F5, модели RUAccent, веса озвучки.

## Установка
```bash
python -m venv venv && source venv/bin/activate        # Windows: venv\Scripts\activate
pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124   # под вашу CUDA
pip install -r dubservice/requirements.txt
python -m dubservice.setup_models                      # веса озвучки (~1.4 ГБ) в data/models
python -m dubservice                                   # http://127.0.0.1:8000
```
Для Linux/Windows код один и тот же. Стадии запускаются подпроцессами текущим интерпретатором, поэтому запускать сервис нужно из того venv, где всё установлено.

## Настройка (переменные окружения)
| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DUB_HOST`, `DUB_PORT` | `127.0.0.1`, `8000` | `0.0.0.0` откроет сервис по сети; тогда обязательно задайте токен |
| `DUB_API_TOKEN` | пусто | общий токен: `Authorization: Bearer …`; веб-страница спросит его сама |
| `DUB_LLM_URL`, `DUB_LLM_MODEL` | `http://localhost:1234/v1`, первая модель сервера | любой OpenAI-совместимый сервер |
| `DUB_DATA_DIR` | `./data` | задачи, база, веса |
| `DUB_ASR_MODEL` | `large-v3` | на слабой карте: `medium` или `small` |
| `DUB_CANDIDATES` | `3` | вариантов на фразу (лучший выбирается проверкой через Whisper) |
| `TB_PUBLIC_KEY`, `TB_SECRET_KEY` | пусто | ключи Teachbase (только чтение курсов и скачивание материалов) |

Ключи Teachbase задавайте только в окружении, в файлы они не пишутся.

## Как это работает
Очередь с одним GPU-воркером. Каждый этап — отдельный процесс, поэтому видеопамять полностью освобождается между этапами
(Whisper, LLM в LM Studio и F5 не конкурируют за карту). Перевод в LM Studio лучше разгружать после этапа (TTL выгрузки модели).

1. **asr** — расшифровка, пословные тайминги, разбивка на предложения, удаление галлюцинаций Whisper (слова нулевой длины).
2. **translate** — пачками по 8 предложений с контекстом и глоссарием (`glossary.json`); у каждой фразы бюджет символов под её тайминг,
   слишком длинные переписываются отдельно.
3. **review** — вы правите текст на странице; индикатор длины `символов/бюджет` краснеет у фраз, которые не влезут в паузу.
4. **dub** — автоподбор референса голоса, озвучка, проверка, сборка.

Защиты озвучки, найденные на пилоте: референс 5–12 с с паузой после (иначе модель «дочитывает» слова референса — «йос», английские фразы);
каждая фраза генерируется несколько раз и выбирается ближайшая к тексту по обратной расшифровке; лишнее в начале и в конце фразы вырезается;
не влезающая в паузу фраза генерируется быстрее, а не растягивается постфактум; если озвучка длиннее видео, удерживается последний кадр.

## API
`GET /api/health` · `GET /api/jobs` · `GET /api/jobs/{id}` · `POST /api/jobs` (multipart: `file`, `review`, `source_lang`) ·
`GET /api/teachbase/courses/{id}/videos` · `POST /api/jobs/teachbase` · `GET|PUT /api/jobs/{id}/units` ·
`POST /api/jobs/{id}/approve` · `POST /api/jobs/{id}/retry?stage=asr|translate|dub` · `GET /api/jobs/{id}/result` (`/source`, `/report`, `/log`) · `DELETE /api/jobs/{id}`

## Режим «курс целиком»
Введите ID курса и нажмите «Перевести курс целиком». Курс читается из Teachbase (только чтение), дальше:

1. **Тексты** (названия, описания, текстовые страницы, задания): перевод с сохранением HTML-разметки, проверка совпадения тегов, правка на странице.
2. **Документы** (PDF): перевод на месте с сохранением вёрстки. Teachbase хранит презентации и документы как PDF-копии, оригиналов pptx/docx через API нет,
   поэтому результат тоже PDF. Текст внутри картинок не переводится.
3. **Видео**: каждое ставится в очередь как обычная задача озвучки; «Утвердить все переводы видео» разом пропускает проверку.
4. **Пакет для ручной загрузки** (`manual_upload/`): переведённые видео и документы + `README.md` с чек-листом: что и куда загрузить.
5. **Отправка текстов в LMS**: создаёт НОВЫЙ курс (исходный никогда не изменяется): разделы, текстовые страницы и задания. Видео, документы, тесты, SCORM и
   встроенные материалы API создать не позволяет, они остаются на ручную загрузку.

Запись в LMS выключена, пока сервис не запущен с `DUB_ALLOW_PUSH=1`, и всегда требует подтверждения; перед этим доступен просмотр плана («Показать, что будет создано»).
Отправка возобновляемая: созданные ID пишутся в `push.json`, повтор после сбоя не создаёт дубликатов.

## Известные ограничения
- Направление зашито: язык оригинала → русский (`TARGET_LANG`, F5-TTS Russian). Другой язык озвучки потребует другой модели.
- Права ключей Teachbase на запись и поведение `POST` проверены только по спецификации API, живую запись нужно пробовать на тестовом курсе.
- Один голос на видео. Несколько дикторов не различаются.
- Текст на экране (слайды) не переводится.
- Пороги (12 символов/с, потолки ускорения) подобраны на одной лекции и настраиваются переменными `DUB_CHARS_PER_SEC`, `DUB_MAX_ATEMPO`, `DUB_MAX_F5_SPEED`.
- Задачи выполняются строго по одной. Перезапуск сервиса возвращает прерванную задачу в очередь.
